# 📊 Sales Performance Analysis & Dashboard 
## Project Overview This project analyzes 10,000 sales transactions to understand business performance, product performance, profitability, and sales trends. The analysis was performed using Python, Pandas, and Matplotlib. 
## Business Questions The project answers the following questions: - 
What is the total sales revenue?
- What is the total profit?
- What is the average order value?
- Which product generates the highest sales?
- Which city generates the highest sales?
- Which category performs best?
- How do sales change over time?
